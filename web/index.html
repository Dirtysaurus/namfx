Network

Own WiFi (hotspot)

Leave the password empty for an open network (easy first connection), then set a password here: 8–63 characters. It applies when the hotspot restarts.

The hotspot is open: anyone in range can connect and control namfx. Set a password.

Auto: when the console finds no known WiFi for 20 s, it opens its own network. Connect your phone to it and open http://10.42.0.1 (the address is also shown at the bottom of the console screen).
